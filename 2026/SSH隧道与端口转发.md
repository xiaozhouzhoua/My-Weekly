# SSH 隧道与端口转发

## 概述

SSH 除了远程登录，还内置了一套**端口转发（Tunneling / Port Forwarding）**能力：
在本地和远程之间建立加密通道，把 TCP 流量「搭」在这条通道上走。它不需要改动防火墙，
也不需要安装额外软件，是最实用的内网穿透 / 安全访问手段之一。

三种转发模式：

| 模式 | 参数 | 方向 | 典型用途 |
|------|------|------|----------|
| 本地转发 | `-L` | 本地端口 → 目标 | 访问远端内网的服务 |
| 远程转发 | `-R` | 远端端口 → 本地 | 把本机服务暴露给远端 |
| 动态转发 | `-D` | 本地 SOCKS 代理 | 当作加密代理上网 |

## 本地转发 -L

把**本机端口**的流量，通过 SSH 服务器转发到**目标主机：目标端口**。

```bash
ssh -L 3306:127.0.0.1:3306 user@jump-server
```

含义：本机 `127.0.0.1:3306` 收到的连接，会从 `jump-server` 出去，连到它眼中的
`127.0.0.1:3306`。

> 注意：`127.0.0.1:3306` 这个目标地址是**相对于 SSH 服务器**解释的，
> 不是相对于你本机。想连跳板机内网里的另一台机器，写成内网 IP：

```bash
ssh -L 5432:192.168.10.20:5432 user@jump-server
```

这样本机 `psql -h 127.0.0.1 -p 5432` 就能连上内网那台 PostgreSQL。

### 后台常驻

加上这几个参数，让隧道安静地在后台跑：

```bash
ssh -N -f -L 3306:127.0.0.1:3306 user@jump-server
```

| 参数 | 作用 |
|------|------|
| `-N` | 不执行远程命令，只做转发 |
| `-f` | 认证后转入后台 |
| `-T` | 不分配伪终端 |

## 远程转发 -R

方向相反：把**SSH 服务器上的端口**，转发回**你本机**的服务。

典型场景：本机跑着一个 Web 服务，想让外网/同事临时访问，但没有公网 IP：

```bash
ssh -R 8080:127.0.0.1:8080 user@public-server
```

之后任何能访问 `public-server` 的人，访问其 `8080` 端口就等于访问你本机的 `8080`。

默认情况下，SSH 服务器只在 `127.0.0.1` 上监听转发端口；要允许外部访问，需在
`sshd_config` 打开：

```
GatewayPorts yes
```

然后：

```bash
ssh -R 0.0.0.0:8080:127.0.0.1:8080 user@public-server
```

> 安全提醒：`GatewayPorts yes` 会把你的内网服务暴露到公网，务必配合防火墙和鉴权。

## 动态转发 -D

在本机开一个 SOCKS5 代理，所有走这个代理的流量都从 SSH 服务器出口：

```bash
ssh -D 1080 -N -f user@server
```

浏览器 / 系统代理指向 `socks5://127.0.0.1:1080` 即可。适合临时绕过网络限制，
或者让所有应用共享同一条加密通道。

## 断线自动重连

纯 `ssh` 隧道网络一抖就断。用 `autossh` 自动拉起：

```bash
autossh -M 0 -N -f -L 3306:127.0.0.1:3306 user@jump-server
```

- `-M 0` 关闭额外的监测端口，让 autossh 只靠连接状态判断
- 配合 `~/.ssh/config` 里的 `ServerAliveInterval 30` / `ServerAliveCountMax 3` 效果更好

也可用 systemd 把隧道托管成服务，实现开机自启、崩溃拉起。

## 常用排查

- 端口被占用：`ssh -vvv -L ...` 看详细日志，或 `netstat -ano | findstr 端口`（Windows）
- 转发目标连不上：先 ssh 登录服务器，从**服务器上** `curl` 目标地址，排除是网络还是权限问题
- 认证卡住：确认能 `ssh user@server` 直接登录；公钥、代理、`known_hosts` 逐个排查

## 小结

- 只想「借服务器访问内网服务」→ `-L`
- 想「让外网访问本机服务」→ `-R`
- 想「把服务器当代理」→ `-D`
- 生产长期使用 → `autossh` 或 systemd 托管，别裸跑 `ssh`
