About

关于本仓库

仓库名 My-Weekly，默认分支 main。目录即时间轴：2023/、2024/、2025/ 各自存放当年的文档，根目录放专题报告与说明文件。

📁 目录结构

  • 2023/ — 命令行、Java、Maven、Redis 等 8 篇
  • 2024/ — 1 篇占位文档
  • 2025/ — PostgreSQL、Shell、AI 工具等 4 篇
  • images/ — 文档引用的图片资源

🚀 访问方式

线上：xiaozhouzhoua.github.io/My-Weekly/
本地：克隆仓库后用任意静态服务器打开本文件，例如
python -m http.server 8000

🛠️ 发布方式

仓库 Settings → Pages → Source 选择 main 分支 / (root)， 入口文件必须叫 index.html，无需工作流。根目录的 .nojekyll 让 Pages 原样发布文件、不做 Jekyll 转换，因此本页可以直接读取同目录的 .md 原文。
